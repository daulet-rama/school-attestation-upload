# Загрузка документов аттестации

Сайт для GitHub Pages: по каждому из 77 документов (15 категорий: как на исходном
сайте плюс раздел №9 «Тәрбие жұмысы») просит загрузить конкретный файл.

* Загруженные файлы хранятся в ветке `uploads`: `manifest.json` + `files/`.
* Публикация — после входа с ключом GitHub (Fine-grained token, только этот
  репозиторий, Contents: Read and write). Ключ хранится только в браузере.
* Без входа файлы сохраняются в браузере как черновик: их можно опубликовать
  позже или скачать архивом ZIP со структурой папок.
* Файлы больше 30 МБ прикрепляются ссылкой на Google Диск.

Скачать всё загруженное:

```bash
git clone --branch uploads https://github.com/daulet-rama/school-attestation-upload.git uploads
```
